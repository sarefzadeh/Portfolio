# Portfolio deploy (static site)

1. Create a GitHub repo and upload these files (index.html, vercel.json, .image-slots.state.json).
2. vercel.com -> Add New Project -> import the repo -> Framework: Other -> Deploy.
3. Project -> Settings -> Domains -> add your domain, then set the DNS records Vercel shows.

No build step, no backend. Alternative: drag the folder onto app.netlify.com/drop.
